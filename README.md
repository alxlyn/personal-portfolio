# alekseilian.com

Personal site of Aleksei Lian: backend engineer and CS student at York University.

- Live: https://alekseilian.com
- Tanish case study: https://alekseilian.com/tanish
- Stack: React + Vite, deployed on Vercel
- Content lives in `src/data/content.js`; the case study is `public/tanish.html`

## Run locally

```bash
npm install
npm run dev
```
